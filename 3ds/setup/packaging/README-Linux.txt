OpenMW for New 3DS {VERSION}
For the New 3DS and New 2DS.

1. Run OpenMW-3DS-Setup-x86_64.AppImage. It finds your Morrowind (English, French or German, from Steam, GOG or the
   disc) or lets you pick its folder.
2. Press Prepare. Your game's files go to the folder you choose.
3. Copy that folder's contents to the root of your SD card.
4. Install the CIA: scan the code the app shows with FBI (Remote Install, then Scan QR Code), or install
   cias/openmw3ds.cia with FBI (https://github.com/Steveice10/FBI/releases/latest) or Cement
   (https://github.com/Synaelle/cement/releases/latest). Then start OpenMW. The first launch takes a while.

To update, run the new version's AppImage: it remembers your folder and only prepares what changed. Copy the folder
to your SD card again, replacing the files there.

It's a CIA and not a .3dsx because the game needs all the memory the New 3DS gives an installed title.
Your game's files are only read, never changed, and none of them are in this download.
